# packages/

被应用复用的内部共享库。每个子目录是一个工作区包（`@nomitr/<目录名>`），**不单独部署**，只作为依赖被 `apps/*` 引用。

## 成员

| 目录 | 包名 | 职责 |
| --- | --- | --- |
| `ui/` | `@nomitr/ui` | 跨应用复用的 UI 组件、样式变量、hooks |
| `shared/` | `@nomitr/shared` | 通用工具函数、类型定义、常量、校验规则 |
| `config/` | `@nomitr/config` | 共享工程配置：lint 规则、构建基础配置、格式化约定 |

## 规则

1. **只放"已经被至少两个应用需要"的东西**。单站点用的组件留在 `apps/*/src`。
2. **不引用 `apps/*`**，`packages/*` 必须能脱离应用独立编译。
3. **包之间保持单向**：`ui → shared`，`config` 被所有包引用，`shared` 不反向依赖 `ui`。
4. 内部包默认 `private: true`，不发布到公共 registry；确需发布时，单独在该包 README 里说明。
5. 每个包都要有明确的入口（`src/index.ts` 或等价文件），外部只能从包入口 import，禁止深路径引用内部文件。
