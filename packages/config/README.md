# @nomitr/config

存放所有应用共享的**工程配置**，避免每个 app 各写一份、逐渐漂移。

## 放什么

- 代码规范配置：lint 规则、格式化选项。
- 构建基础配置：编译目标、路径别名、产物目录约定的公共片段。
- 编辑器与提交约定：`.editorconfig` 的补充、提交信息规范。

## 不放什么

- 运行时代码。这个包被引用的是配置文件，不应该出现在应用产物里。
- 密钥、令牌、环境变量值。敏感信息通过 `.env` 注入，不进仓库。

## 建议的结构

按工具分目录，每个工具一个入口，例如：

```text
config/
├─ eslint/        # 基础规则 + 各环境（web / node / test）变体
├─ build/         # 构建器共享配置
└─ README.md
```

具体子目录等技术选型确定后再补，当前只保留本说明。子目录一旦建立，就在下方补一行职责说明。
