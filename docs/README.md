# docs/

项目文档。文档和代码同仓，改结构时在同一个提交里改文档，避免说明与实际目录脱节。

## 目录

| 路径 | 内容 |
| --- | --- |
| `architecture.md` | 目录结构、分层规则、依赖方向、扩展方式 |
| `adr/` | 架构决策记录（Architecture Decision Record），一次决策一个文件 |

## 写作约定

- 面向"三个月后的自己"：写清为什么这么分，而不只是分成了什么。
- 结构变更时同步更新：根 `README.md` 的目录树、`docs/architecture.md` 的依赖图、对应模块的 README。
- 已有决策被推翻时，新增 ADR 说明新结论，并在旧 ADR 顶部标注 "已被 ADR-XXXX 取代"，不要直接改写历史。
