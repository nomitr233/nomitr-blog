## 模板

```markdown
# NNNN. 决策标题

- 状态：提议 / 已接受 / 已取代（由 ADR-XXXX 取代）
- 日期：YYYY-MM-DD

## 背景
为什么需要做这个决定，当前遇到了什么问题。

## 备选方案
1. 方案 A：优缺点
2. 方案 B：优缺点

## 结论
选了什么，为什么。

## 影响
需要跟着改的文件、流程、约定。
```
